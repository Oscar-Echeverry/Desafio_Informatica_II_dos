# Ude@Book – Desafío II de Informática II

Ude@Book es una red social desarrollada en **C++**, utilizando programación orientada a objetos y una interfaz por consola.

## Trabajo realizado

Se implementó la carga y el guardado de datos, el inicio de sesión, la administración de amistades, las sugerencias de usuarios, el envío y la consulta de mensajes por fechas, y la visualización de álbumes y fotos con likes. También se incorporó un medidor de iteraciones y memoria. Se preparó una base de datos de prueba con **1.000 usuarios** y mensajes distribuidos en distintas fechas y horas.

**Trabajo realizado por:** Luna y Oscar.
